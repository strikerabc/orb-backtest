# Outputs Directory

This directory stores backtest results, analysis outputs, and trading system reports.

## File Structure

```
outputs/
├── orb_backtest_results.json          # Standard backtest results
├── orb_regime_analysis.json           # Regime analysis findings
├── orb_full_span_exploration.json     # Parameter optimization results
└── trade_journals/                     # Per-run trade logs
```

## Output Formats

### Backtest Results
- **Format:** JSON
- **Contains:** Trade-by-trade results, performance metrics, risk statistics
- **Schema:** See `src/journal.py` for data structure

### Analysis Reports
- **Format:** JSON with summary statistics
- **Contains:** Sharpe ratios, win rates, consistency metrics, yearly breakdowns

## Note

Output files are **not committed to git** (excluded via `.gitignore`).

Results are regenerated by running backtest and analysis scripts in `tools/analysis/`.

## Viewing Results

```python
import json

# Load backtest results
with open("outputs/orb_full_span_exploration.json", "r") as f:
    results = json.load(f)

# Access top configurations
top_configs = results["top_sharpe"]
```
